# 20 个实验策略 · 概述

> 本文件与 `对局报告.md` 同属一次万局随机组合实验的交付物。策略实现在 `experiments/strategies20.mjs`，批量脚本在 `experiments/run-10000.mjs`。

## 实验口径

- **对局数**：10,000 局（全部跑到 `game.over`，无截断、无抽样）
- **随机种子**：`20261106`（每局由主种子 + 局号派生，与并行度无关）
- **并行**：8 个 worker，耗时 8.9 分钟
- **棋盘 / 回合**：50x50 = 2500 格，每局上限 120 回合，全部使用 `CFG_DEF` 默认参数
- **抽签**：每局从 20 策略无放回抽 4 个，再随机分配到 A/B/C/D
- **规则来源**：`server/engine.js（未修改）`，本实验未修改任何现有代码

所有策略遵循 `buildActions(view, game, ai)` 契约，共用同一套寻路 / 采矿 / 攻击工具，差异只在**目标选择、路径形状、开战时机与风险偏好**。动作合法性由 `server/engine.js` 的裁判最终裁定；脚本自身不修改规则、参数或胜负判定。

「位置等权胜率」是对 A/B/C/D 四个位置分别算胜率再取平均，用来消除四家基地位置不对称带来的偏差；原始胜率附 95% 置信区间。平均基准胜率为 25%（四家必有一胜）。

## 逐个说明

### 01 · 蜂群扩散（`swarm` · 扩张类）

- **思路**：不设主目标，全员按固定扇区径向散开，用最多条移动轨迹把中立地刷成己方色。
- **具体做法**：每个单位占一个 8 向角度，半径随回合在 3–25 格间周期往返；不采矿、不主动接战，只靠走过翻旗；目标被挡就换相位再试。
- **风险 / 弱点**：没有守军，敌方穿插进来时大片相连领土可能被包围判定整块夺走；也不造兵补充。
- **实测**：样本 2,037 局 · 位置等权胜率 **0.78%**（总榜第 18）· 原始胜率 0.79% ± 0.38% · 平均名次 3.10
- **局面数据**：终局领土 213.7 格（第 60 回合 259.9 格，后半程 -46.2）· 平均击杀 2.08 · 存活单位 3.72 · 结余资源 0.0
- **生存 / 结局**：被亡国率 32.99% · 出场局出现征服结局 24.74%、其中该策略获胜 0.00% · 提前结束率 24.55%
- **位置表现**：A 0.98% / B 1.93% / C 0.20% / D 0.00%
